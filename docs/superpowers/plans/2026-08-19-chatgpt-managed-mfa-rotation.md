# ChatGPT 登录后托管 MFA 轮换实施计划

1. 为 MFA 协议管理器编写失败测试，覆盖新增、轮换、激活失败和脱敏。
2. 实现 `ChatGPTMfaManager`，并接入 Web AT 登录与 OAuth RT 登录的成功出口。
3. 为旧 TOTP 错误后的邮箱因子回退编写测试并实现。
4. 扩展邮箱服务适配器，将新 secret、恢复码及风险标记写入账号上下文。
5. 扩展登录弹窗和任务 payload，默认启用 MFA 轮换并展示控制权风险。
6. 运行后端、前端定向测试和完整测试/构建。
7. 提交并推送主仓库，原子部署到生产服务器，执行授权测试账号验证和服务健康检查。
