# 修改 MFA 后退出所有设备并重新登录

沿用登录任务的 MFA 开关。新增或轮换 MFA 后，先通过现有 WAL 和凭据提交保存新密钥、恢复码，再请求 ChatGPT 的 `POST /backend-api/accounts/logout_all`。该接口已从 2026-09-22 ChatGPT 公共网页安全设置代码核对，网页使用无请求体的 POST。

服务端确认成功后，销毁旧的手机 OAuth 缓存和浏览器上下文。完整登录路径创建独立 OAuth 客户端，使用保存的新 MFA 重新认证；分阶段登录路径创建独立 Web 客户端，重新获取 AT、session 和手机授权事务。Codex2API 沿用成功结果后的同步入口，只接收新凭据。

退出失败、响应不明确、新登录失败或凭证缺失都终止本次结果；保留已激活 MFA 的持久记录供重试恢复。Free 订阅仍在修改 MFA 和退出设备之前删除。普通未修改 MFA 的登录保持现有行为。平台强制绑定 MFA 也执行相同退出及重登规则，重复强制绑定时中止，避免无限轮换。

验证：请求协议与脱敏错误、持久化/退出/重登顺序、新会话隔离、AT/RT 两种路径、强制绑定、失败阻止成功结果、Free 规则、停止任务、UI 流程说明。发布前执行相关回归和前端构建，服务器备份数据库、检查任务空闲、原子切换版本并验证 HTTP 和服务状态。

持久恢复状态采用独立设备退出记录：MFA 激活时同事务写入待退出代次；退出确认后保留“已退出、待保存新凭证”状态。AT/RT 首次成功持久化时按代次原子消费记录。重试不会继承旧 RT 或 Cookie，也不会因已确认的退出再次撤销刚建立的会话。MFA WAL 提升或服务重启不会丢失该记录。自动 RT 维护遇到未完成记录时强制完整登录。

验证结果：初始化隔离测试数据库后，相关后端测试 520 项和 54 个子测试通过；前端登录组件与流程测试 23 项通过，TypeScript/Vite 生产构建通过。独立审查发现的重试义务丢失、旧 RT 合并保留、数据库实例不一致和一次性代次字段继承均已加入回归并修复。未使用真实账号批量退出作为测试。
