# 任务运行探针额度展示设计

## 目标

在“任务运行”卡片中隐藏内部任务 ID，并让 ChatGPT 自动鉴权探针直接展示本轮探针汇总出的 Codex2API 剩余可用额度。

## 数据来源

不新增接口。`GET /tasks/summary` 已通过任务 `meta` 返回 `automation`、`estimated_remaining_usd` 等字段；页面复用这个轻量摘要，不为每张卡片再次请求 Codex2API，也不加载完整任务详情。

## 展示规则

- 所有任务卡片都不显示 `task_*` ID。
- 日志抽屉标题不显示任务 ID；ID 仍在组件状态中供日志详情、删除和轮询使用。
- 自动鉴权任务完成且额度为有效非负数时，显示“剩余可用额度”和两位小数美元金额，例如 `$98.85`。
- 自动鉴权任务处于 `pending` 或 `running` 时显示“本次探针额度统计中”。
- 自动鉴权任务已结束但额度缺失或非法时显示“本次探针额度未生成”。
- 普通任务只保留平台与来源，不显示探针额度占位内容。

## 响应式布局

- 内容区允许在固定侧栏旁收缩，手机端页面内边距缩小到 12px。
- 任务卡片使用移动优先的 CSS Grid：额度与平台占满首行，状态和耗时并排，进度、统计标签和操作按钮分别占满后续行。
- 成功、失败、跳过等短数字短语保持单行；标签与按钮组允许按项目换行，不允许把文字逐字压成竖排。
- 1100px 以上恢复桌面五列紧凑布局；触控设备上的操作按钮高度至少 44px。

## 边界处理

额度输入可为字符串或数字。只接受有限、非负数；统一格式化为两位小数。`0` 是有效额度，显示 `$0.00`。历史任务缺少该字段时不伪造为零。

## 测试

在 `RunningTasks.test.tsx` 覆盖：完成探针金额展示、运行中状态、非法/缺失额度、普通任务无额度标签、响应式区域和统计短语不拆字，以及卡片和日志抽屉均不泄露任务 ID。`App.test.tsx` 覆盖内容区可收缩及移动端样式入口。现有摘要轮询、日志和删除测试继续通过。

## 发布

与侧栏固定修复一起构建前端并创建新的不可变 release，只重启 `any-auto-register.service`，保留当前 release 作为回滚目标。
